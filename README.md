# Effect Craft

### Craft Better Effects. Create Without Limits.

**Effect Craft** is an open-source creative tools project focused on building useful scripts, extensions, plugins, and workflow automation tools for video editors, motion designers, and digital creators.

Our goal is simple: make creative workflows faster, smarter, more accessible, and less repetitive through practical software tools.

## What is Effect Craft?

Effect Craft is a growing collection of independent creative utilities designed to solve real-world problems in video editing and motion design.

Instead of spending time on repetitive manual tasks, creators can use our tools to automate workflows and focus more on creativity.

## What We Build

- **Scripts:** Automation scripts and productivity utilities.
- **Plugins:** Tools that extend creative software functionality.
- **Extensions & Panels:** Custom interfaces and workflow enhancements.
- **Audio Tools:** Beat detection, audio analysis, and synchronization utilities.
- **Workflow Automation:** Tools that reduce repetitive editing tasks.
- **Creative Utilities:** Small but useful tools for everyday production workflows.

## Project Compatibility

Each tool may target a different host application or runtime.

Compatibility, requirements, installation instructions, and supported versions are documented individually for each project.

## Our Principles

- Free and open-source.
- Practical solutions over unnecessary complexity.
- Clean and user-friendly interfaces.
- Transparent development.
- Community contributions.
- No unnecessary restrictions on creative workflows.
